# Аня + Лёша — сайт для GitHub Pages

Готовая версия для телефона и компьютера: сердечки, настройки фона, добрые фразы, кубик занятий, мини-игра и карта.

## Как загрузить

1. Распакуй `MySite-GitHub.zip`.
2. В своём репозитории GitHub выбери **Add file → Upload files**.
3. Загрузи **содержимое архива**, а не сам ZIP. Файл `index.html` должен лежать в корне репозитория, рядом с `TEXTS.json`, `app.js` и остальными файлами.
4. Нажми **Commit changes**.
5. Открой **Settings → Pages**.
6. В разделе **Build and deployment** выбери **Deploy from a branch**, свою ветку (обычно `main`) и папку **/(root)**. Нажми **Save**.
7. После успешной публикации ссылка появится в этом же разделе. Это будет адрес вида `https://имя.github.io/репозиторий/`.

Инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Важно про желания

**GitHub Pages не запускает сервер на твоём ПК. В этой версии желания НЕ отправляются Лёше и НЕ сохраняются на его компьютере.**

Окно желаний позволяет писать черновик, который остаётся в браузере посетителя. Кнопка отправки отключена, и это прямо объясняется на сайте. Для настоящего приёма желаний понадобится отдельный сервер или сервис формы. Локальная версия сайта с `START.bat` остаётся отдельной и продолжает сохранять отправленные желания на ПК.

## Как менять тексты

Все надписи и фразы — в `TEXTS.json`. Открой его на GitHub, нажми карандаш, измени текст справа от двоеточия и сохрани изменения. GitHub Pages обновит сайт после новой публикации.

- `главная` — заголовки и приветствие.
- `поддержка → фразы` — добрые фразы.
- `кубик → общие`, `для_ани`, `для_лёши` — отдельные списки занятий.
- `игра`, `желания`, `карта`, `настройки` — тексты соответствующих блоков.

Сохраняй двойные кавычки, скобки и запятые. Новую строку внутри фразы записывай как `\n`. Вставки `{count}`, `{rounds}`, `{km}` оставляй для чисел. Надписи выводятся обычным текстом, HTML не нужен.

## Что внутри

Только файлы сайта. Личные ключи, ответы и тестовые данные не включены. Все картинки, стили и скрипты локальные, внешние библиотеки не нужны. Для публикации сборка не требуется. `.nojekyll` отключает обработку Jekyll; `.gitignore` помогает не добавить локальные ответы при работе через Git.

Карта: [Natural Earth](https://github.com/nvkelso/natural-earth-vector), public domain. Расстояние между Нарвой и Советским рассчитано по прямой между центрами городов, не по дороге.
